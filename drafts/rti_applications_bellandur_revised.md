# RTI Applications for Road Infrastructure Transparency - Bellandur (Mahadevapura Zone)

**Based on:** Strategic Transparency Framework (framework.md)
**Target Portal:** rtionline.karnataka.gov.in
**Total Applications:** 2 (Split-Application Strategy)
**Fee:** ₹10 per application (₹20 total)

---

## STRATEGIC RATIONALE

### Why Two Applications?

Roads in Bellandur are governed by **two separate jurisdictions**:

| Category | % of Network | Custodian | Examples |
|----------|-------------|-----------|----------|
| **Ward Roads** | ~80% | Executive Engineer (Mahadevapura Division) | Internal layout roads, cross streets, village roads |
| **Arterial/Major Roads** | ~20% | Chief Engineer (Projects Central) at BBMP HQ | ORR, Sarjapur Main Road, Varthur Main Road |

Filing a single application causes **Section 6(3) transfer limbo** where the entire application bounces between departments.

### The Job Code as Primary Key

The **Job Code** (format: `150-19-000XXX`) is the atomic unit that links:
- Road → Contractor → Budget → Officials → DLP Status

Without Job Codes, building a relational database is impossible.

## APPLICATION A: WARD ROADS (The "High-Yield" Application)

**This captures 80% of roads - internal layout roads that directly affect residents.**

### Filing Instructions

| Field | Value |
|-------|-------|
| **Portal** | rtionline.karnataka.gov.in |
| **Public Authority** | Bruhat Bengaluru Mahanagara Palike (Mahadevapura Zone) BBMP |
| **Payment** | ₹10 via Internet Banking/UPI |

### Text for RTI Request (2,847 characters)

```
To: Public Information Officer (PIO),
Office of the Executive Engineer,
BBMP Mahadevapura Division,
Mahadevapura Zone, Bengaluru.

Subject: Request for "Road History," "Work Order," and "DLP" Data for Ward No. 150 (Bellandur) - Period 2018-2025 - For Public Transparency Portal.

Respected Sir/Madam,

Under the RTI Act 2005, I request the following structured data regarding Road Infrastructure Works (Capital & Maintenance) executed in Ward No. 150 (Bellandur) and its constituent areas (including Green Glen Layout, Kaikondrahalli, Kasavanahalli, Haralur, Junnasandra) for the financial years 2018-19 to 2024-25.

1. DATABASE OF EXECUTED WORKS:
Please provide a certified tabular list (Excel/CSV format requested) of ALL road works (Asphalting, Concreting, Pot-hole filling, Drain remodeling, Footpath) executed in the ward. For EACH work, provide:
   a) Job Code / P-Code (e.g., 150-19-0000XX).
   b) Name of Work (Administrative Sanction Description).
   c) Name of the Agency/Contractor (Legal Entity Name).
   d) Work Order (WO) Number & Date.
   e) Work Order Amount (Sanctioned Cost).
   f) Actual Completion Date (as per Measurement Book).
   g) Defect Liability Period (DLP) Status: Specific Start Date and End Date of the DLP for each work.

2. EXPENDITURE & ACCOUNTABILITY MAPPING:
For the works identified in Item 1:
   a) Total Amount Paid to the contractor to date (Gross Bill Amount).
   b) Designation & Name of the Officials (AE, AEE, and Executive Engineer) who were the "Check Measurement" officers responsible for certifying the quality of these specific works.
   c) Copy of the "DLP Register" or "Road History Register" for this ward, showing the current liability status of all roads.

3. CONTACT INFORMATION FOR PUBLIC GRIEVANCE:
Please provide the current official contact details (Name, Official Designation, Office Address, Official Mobile No, and Official Email ID) for:
   a) The Executive Engineer (Mahadevapura Division).
   b) The Assistant Executive Engineer (AEE) for Bellandur Sub-division.
   c) The Assistant Revenue Officer (ARO) for Bellandur.

4. FORMAT & SECTION 4 DISCLOSURE:
I request this data in digital format (CD/DVD/Email) to minimize paper use and facilitate data analysis for public interest, as mandated by Section 4(1)(b) of the RTI Act regarding computerization of records. If "Road History" is available on the BBMP "Road History 2.0" or "e-Aasthi" portal, please provide the specific URL and the list of available attributes.

Note: If any road (e.g., ORR, Sarjapur Main Road) falls under "Major Roads" or "Projects Central" jurisdiction, kindly provide the data available with your office (Ward Roads) and transfer only the specific relevant part of this application to the concerned PIO under Section 6(3). Do not transfer the entire application.
```

## APPLICATION B: MAJOR/ARTERIAL ROADS (The "High-Value Projects" Application)

**This captures ORR, Sarjapur Road, Varthur Road - high-budget projects with 5-10 year DLPs.**

### Filing Instructions

| Field | Value |
|-------|-------|
| **Portal** | rtionline.karnataka.gov.in |
| **Public Authority** | Bruhat Bengaluru Mahanagara Palike (Office of the Commissioner) |
| **Payment** | ₹10 via Internet Banking/UPI |

### Text for RTI Request (2,891 characters)

```
To: Public Information Officer (PIO),
Office of the Chief Engineer (Road Infrastructure / Projects),
BBMP Head Office, N.R. Square, Bengaluru - 560002.

Subject: Request for Data on Arterial/Sub-Arterial Roads in Mahadevapura Zone (ORR, Sarjapur Road, Varthur Road) - Period 2015-2025.

Respected Sir/Madam,

Under the RTI Act 2005, I request the following structured data regarding Major Road Infrastructure Works executed by the Projects Division (Central), Road Infrastructure Division, or Traffic Engineering Cell on Arterial and Sub-Arterial roads passing through or adjacent to Ward No. 150 (Bellandur) for the financial years 2015-16 to 2024-25.

1. DATABASE OF MAJOR ROAD WORKS:
Please provide a certified tabular list (Excel/CSV format requested) of ALL major road works (TenderSURE, White-topping, Asphalting, Signal-free corridors) executed on:
   - Outer Ring Road (ORR) - Bellandur to Marathahalli stretch
   - Sarjapur Main Road
   - Varthur Main Road
   - Any other Arterial/Sub-Arterial road in the jurisdiction

For EACH work, provide:
   a) Job Code / Package ID / Tender Reference Number.
   b) Name of Work (Administrative Sanction Description).
   c) Name of the Agency/Contractor (Legal Entity Name & Address).
   d) Contract/Work Order Number & Date.
   e) Sanctioned Project Cost.
   f) Actual Expenditure to date.
   g) Date of Completion (as per Final Measurement Book).
   h) Defect Liability Period: Start Date, End Date, and Duration (3/5/10 years).
   i) Performance Guarantee / Security Deposit amount held.

2. CONTRACTOR ACCOUNTABILITY:
For each work identified above:
   a) Name & Designation of the Superintending Engineer and Executive Engineer who supervised the project.
   b) Any defects reported during DLP period and rectification status.
   c) Any penalties imposed or security deposits forfeited.
   d) Current status: Under DLP / DLP Expired / Maintenance transferred to Zone.

3. WHITE-TOPPING & TENDERSURE SPECIFIC DATA:
For concrete/white-topped roads (which have 10-year DLP):
   a) Complete list of white-topped stretches in Mahadevapura Zone.
   b) Contractor name and DLP end date for each.
   c) Quality audit reports conducted, if any.

4. CONTACT INFORMATION:
Please provide current official contact details (Name, Designation, Office Address, Phone, Email) for:
   a) Chief Engineer (Road Infrastructure / Major Roads).
   b) Executive Engineer (Projects - Mahadevapura jurisdiction).
   c) Nodal Officer for ORR maintenance.

5. FORMAT:
I request data in digital format (Excel/CSV via Email/CD) as per Section 4(1)(b) of the RTI Act.

Note: This application pertains ONLY to roads under "Projects Central" / "Major Roads" jurisdiction. Ward-level internal roads are being requested separately from the Mahadevapura Zonal Office.
```

## POST-FILING: CONTINGENCY HANDLING

### Scenario 1: "Data Not Available in Requested Format"

**PIO Response:** "The data is not available in Excel. Please come to the office and inspect files."

**Your Action:**
1. This is a delay tactic. The Work Order Register (Form PW-III) is a statutory document.
2. Cite **Section 4(1)(b)(vi)** of RTI Act in First Appeal.
3. If forced to inspect: Take a portable scanner/camera. Photograph the entire register. Use OCR to digitize.

### Scenario 2: Section 6(3) Transfer of Entire Application

**PIO Response:** "Transferred to Head Office / Zonal Office."

**Your Action:**
1. File **First Appeal** immediately with the Appellate Authority (Superintending Engineer).
2. Argument: "Application specifically requested Ward Roads/Major Roads respectively. PIO erred in transferring entire application instead of providing available information and transferring only the remainder."

### Scenario 3: "DLP Register Not Maintained"

**PIO Response:** "No DLP Register is maintained for this ward."

**Your Action:**
1. This is an **admission of maladministration**.
2. File complaint with:
   - Technical Vigilance Cell (TVCC), BBMP
   - Karnataka Lokayukta
3. Use this admission in your portal: "BBMP admits it does not track contractor warranties."

## DATABASE SCHEMA FOR WEB PORTAL

The RTI responses should populate this relational structure:

### Table: `roads`
| Field | Type | Source |
|-------|------|--------|
| road_id | PRIMARY KEY | Generated |
| road_name | VARCHAR | RTI Item 1b |
| ward_number | INT | 150 |
| start_lat_long | GEOMETRY | OSM/Crowdsourced |
| end_lat_long | GEOMETRY | OSM/Crowdsourced |
| surface_type | ENUM | RTI Item 1 |
| road_class | ENUM | Ward/Arterial |

### Table: `works`
| Field | Type | Source |
|-------|------|--------|
| job_code | PRIMARY KEY | RTI Item 1a |
| road_id | FOREIGN KEY | Mapped |
| description | TEXT | RTI Item 1b |
| contractor_id | FOREIGN KEY | Linked |
| wo_number | VARCHAR | RTI Item 1d |
| wo_date | DATE | RTI Item 1d |
| sanctioned_cost | DECIMAL | RTI Item 1e |
| actual_paid | DECIMAL | RTI Item 2a |
| completion_date | DATE | RTI Item 1f |

### Table: `contractors`
| Field | Type | Source |
|-------|------|--------|
| contractor_id | PRIMARY KEY | Generated |
| legal_name | VARCHAR | RTI Item 1c |
| address | TEXT | RTI App B |
| registration_class | VARCHAR | If available |

### Table: `officials`
| Field | Type | Source |
|-------|------|--------|
| official_id | PRIMARY KEY | Generated |
| name | VARCHAR | RTI Item 2b |
| designation | VARCHAR | RTI Item 2b |
| tenure_start | DATE | Cross-referenced |
| tenure_end | DATE | Cross-referenced |

### Table: `dlp_status`
| Field | Type | Source |
|-------|------|--------|
| dlp_id | PRIMARY KEY | Generated |
| job_code | FOREIGN KEY | RTI Item 1a |
| start_date | DATE | RTI Item 1g |
| end_date | DATE | RTI Item 1g |
| status | ENUM | Calculated: Active/Expired |
| defects_reported | TEXT | RTI App B Item 2b |

## THE DLP ALGORITHM (Core Portal Feature)

```
User selects road →
  Query: SELECT * FROM works
         WHERE road_id = [selected]
         ORDER BY completion_date DESC
         LIMIT 1

  IF current_date < dlp_end_date:
    Display: "🟢 UNDER WARRANTY"
    Message: "This road is under warranty by [Contractor] until [Date].
              BBMP cannot spend public money to fix this.
              Click here to file a complaint demanding contractor repair."
    Contact: [Contractor details if available]

  ELSE:
    Display: "🔴 WARRANTY EXPIRED"
    Message: "This road is out of warranty since [Date].
              Maintenance is the responsibility of BBMP AEE [Name]."
    Contact: [AEE contact from RTI Item 3]
```
