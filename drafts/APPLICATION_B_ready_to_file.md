```
✓ COPY AS-IS — paste this entire block into the RTI text box

Under the Right to Information Act, 2005, I request the following information from the Office of the Chief Engineer (Road Infrastructure / Projects), BBMP, regarding major road infrastructure works on arterial and sub-arterial roads in the Mahadevapura Zone area (specifically roads passing through or adjacent to Ward No. 150, Bellandur) for the financial years 2015-16 to 2024-25.

1. DATABASE OF MAJOR ROAD WORKS:
Provide a certified tabular list (Excel/CSV preferred) of ALL road works (TenderSURE, White-topping, Asphalting, Signal-free corridors, Grade separators) executed on:
a) Outer Ring Road (ORR) — Bellandur to Marathahalli stretch.
b) Sarjapur Main Road.
c) Varthur Main Road.
d) Any other Arterial or Sub-Arterial road under Projects Central jurisdiction in this area.
For EACH work, provide:
i) Job Code / Package ID / Tender Reference Number.
ii) Name of Work (Administrative Sanction Description).
iii) Name of the Agency/Contractor (Legal Entity Name and Address).
iv) Contract/Work Order Number and Date.
v) Sanctioned Project Cost.
vi) Actual Expenditure to date.
vii) Date of Completion (as per Final Measurement Book).
viii) Defect Liability Period: Start Date, End Date, and Duration (in years).
ix) Performance Guarantee / Security Deposit amount currently held.

2. CONTRACTOR ACCOUNTABILITY:
For each work identified above:
a) Name and Designation of the Superintending Engineer and Executive Engineer who supervised the project.
b) Defects reported during DLP and rectification status (open/closed).
c) Penalties imposed or security deposits forfeited, if any.
d) Current status: Under DLP / DLP Expired / Maintenance transferred to Zone.

3. WHITE-TOPPING SPECIFIC DATA:
For all concrete/white-topped road stretches in Mahadevapura Zone:
a) Complete list of white-topped stretches with road name and length.
b) Contractor name and DLP end date for each stretch.

4. CONTACT INFORMATION:
Current official contact details (Name, Designation, Office Address, Official Mobile, Official Email) for:
a) Chief Engineer, Road Infrastructure / Major Roads, BBMP.
b) Executive Engineer, Projects Division with jurisdiction over Mahadevapura Zone.
c) Nodal Officer for ORR maintenance coordination.

5. FORMAT:
I request data in digital format (Excel/CSV via email or CD) under Section 4(1)(b) of the RTI Act.

Note: This application pertains only to roads under Projects Central / Major Roads jurisdiction. Ward-level internal roads in Ward 150 are being requested separately from the Mahadevapura Zonal Office.
```

## WHAT TO EXPECT IN THE RESPONSE

The ideal response is an Excel/CSV file or a table containing:

| Job Code / Pkg ID | Road / Work Name | Contractor | WO No. | Sanctioned Cost | Actual Spend | Completion Date | DLP End | Status |
|---|---|---|---|---|---|---|---|---|
| PRJ-ORR-XXX | ... | ... | ... | ... | ... | ... | ... | Under DLP / Expired |

White-topping and TenderSURE projects in particular should have long DLPs (5–10 years), making them the most valuable entries for the portal's warranty-tracking feature.

If the response is a letter with vague statements and no data, refer to the contingency guide in `rti_applications_bellandur_revised.md`.
